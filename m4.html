📡 What is DHCP?

DHCP (Dynamic Host Configuration Protocol) is a network protocol that automatically assigns IP addresses and other network configuration parameters to devices connecting to a network. Instead of manually configuring each device, DHCP servers distribute IP addresses from a pool, making network management efficient and scalable.

Why DHCP Matters

🚀 Automation

Automatically assigns IP addresses without manual intervention, reducing configuration errors and administrative overhead.

📊 Scalability

Easily supports networks with hundreds or thousands of devices, from small offices to large enterprises.

♻️ IP Reuse

Leases IP addresses for a specific time period, allowing reuse when devices disconnect from the network.

🔧 Configuration

Provides additional configuration parameters: DNS servers, default gateway, subnet mask, and more.

DHCP Process Flow

1

DHCPDISCOVER

Client broadcasts a request to find DHCP servers on the network.

2

DHCPOFFER

DHCP server responds with an IP address and lease offer.

3

DHCPREQUEST

Client confirms acceptance of the IP address and lease terms.

4

DHCPACK

Server confirms the lease assignment; client configures its network settings.

🔍 Key DHCP Concepts

DHCP Pool

A range of IP addresses configured on the DHCP server that can be assigned to clients. For example:

! Define a DHCP pool named "OFFICE-POOL"
ip dhcp pool OFFICE-POOL
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
dns-server 8.8.8.8 8.8.4.4

Lease Time

The duration for which an IP address is assigned to a client before renewal is required. Default is usually 1 day (86400 seconds).

ip dhcp pool OFFICE-POOL
lease 3 0 0 ! 3 days
lease 0 12 0 ! 12 hours

Excluded Addresses

IP addresses that are excluded from DHCP assignment, typically used for servers, routers, or static devices.

ip dhcp excluded-address 192.168.1.1 192.168.1.50
ip dhcp excluded-address 192.168.1.250 192.168.1.254

DHCP Relay

Enables DHCP client requests to be forwarded to a DHCP server on a different network segment.

interface FastEthernet 0/1
ip helper-address 192.168.2.10 ! DHCP server IP

Verification Commands

show ip dhcp pool ! Display DHCP pool details
show ip dhcp binding ! Show assigned leases
show ip dhcp server statistics ! View DHCP statistics
show ip dhcp conflict ! Display IP conflicts

🛠️ Step-by-Step DHCP Configuration

Let's configure DHCP on a Cisco IOS router for a corporate network with two departments.

Step 1: Plan Your Network

Network Layout:

Router: 192.168.1.1

DHCP Pool (Office): 192.168.1.100 - 192.168.1.150

DHCP Pool (Guest): 192.168.2.100 - 192.168.2.150

DNS Servers: 8.8.8.8, 8.8.4.4

Step 2: Exclude Static IP Addresses

Prevent DHCP from assigning these addresses:

Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.99
Router(config)# ip dhcp excluded-address 192.168.1.200 192.168.1.254
Router(config)# ip dhcp excluded-address 192.168.2.1 192.168.2.99

Step 3: Create DHCP Pool for Office Network

Router(config)# ip dhcp pool OFFICE-POOL
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8 8.8.4.4
Router(dhcp-config)# lease 1 0 0 ! 1 day lease
Router(dhcp-config)# exit

Step 4: Create DHCP Pool for Guest Network

Router(config)# ip dhcp pool GUEST-POOL
Router(dhcp-config)# network 192.168.2.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.2.1
Router(dhcp-config)# dns-server 8.8.8.8 8.8.4.4
Router(dhcp-config)# lease 0 4 0 ! 4 hour lease (shorter for guest)
Router(dhcp-config)# exit

Step 5: Verify Configuration

To prevent the router interface itself from requesting an IP:

Router(config)# interface FastEthernet 0/0
Router(config-if)# ip dhcp server ! Ensure server is enabled
Router(config-if)# no ip dhcp client
Router(config-if)# exit

⚙️ Advanced Configuration Topics

DHCP Relay Agent (DHCP Forwarder)

Use when DHCP server is on a different subnet. The relay agent forwards DHCP requests:

! On the router interface where clients are connected
Router(config)# interface FastEthernet 0/1
Router(config-if)# ip helper-address 10.0.1.10 ! DHCP server IP
Router(config-if)# exit

DHCP Conflict Detection

View and resolve IP address conflicts:

show ip dhcp conflict

IP address Detection method Detection time
192.168.1.150 Ping Mar 14 2024 03:22 PM

! Clear conflicts
clear ip dhcp conflict 192.168.1.150

DHCP Option 82 (Circuit ID)

Enable detailed DHCP tracking and identification:

Router(config)# ip dhcp server option 82 information check
Router(config)# ip dhcp relay information check

👤 Individual Activity: DHCP Configuration Challenge

Scenario

You are a network administrator for a small company with 3 VLANs. Configure a DHCP server on the main router to serve all three networks:

  • VLAN 10 (HR): Network 192.168.10.0/24, Lease 1 day
  • VLAN 20 (Finance): Network 192.168.20.0/24, Lease 3 days
  • VLAN 30 (IT): Network 192.168.30.0/24, Lease 2 hours

DNS servers for all: 1.1.1.1 and 1.0.0.1

Task Requirements

  1. Exclude the first 50 IPs in each network (for static devices)
  2. Create three DHCP pools with appropriate lease times
  3. Configure DNS servers for each pool
  4. Set default routers (.1 for each network)
  5. Write verification commands to check all three pools
!--- Exclude Static Addresses ---
ip dhcp excluded-address 192.168.10.1 192.168.10.50
ip dhcp excluded-address 192.168.20.1 192.168.20.50
ip dhcp excluded-address 192.168.30.1 192.168.30.50

!--- HR VLAN DHCP Pool ---
ip dhcp pool HR-POOL
network 192.168.10.0 255.255.255.0
default-router 192.168.10.1
dns-server 1.1.1.1 1.0.0.1
lease 1 0 0

!--- Finance VLAN DHCP Pool ---
ip dhcp pool FINANCE-POOL
network 192.168.20.0 255.255.255.0
default-router 192.168.20.1
dns-server 1.1.1.1 1.0.0.1
lease 3 0 0

!--- IT VLAN DHCP Pool ---
ip dhcp pool IT-POOL
network 192.168.30.0 255.255.255.0
default-router 192.168.30.1
dns-server 1.1.1.1 1.0.0.1
lease 0 2 0

!--- Verification Commands ---
show ip dhcp pool
show ip dhcp binding
show ip dhcp server statistics

👥 Group Activity: Multi-Location DHCP Deployment

Your organization has 2 office locations. Configure DHCP to handle the following:

• VLAN 300 (Guests): 10.1.3.0/24, Max 30 devices (2hr lease)
