Real-Life Scenario: The Coffee Shop Problem

Imagine you just opened "Brew & Byte Café" — a coffee shop where students come to study. Customers keep asking: "What's the Wi-Fi password?" You need to set up a wireless network that's fast, secure, and covers the whole shop. But how do you choose the right equipment? What settings do you configure? That's exactly what this lesson teaches you.

1 What is Wireless Networking?

A wireless network lets devices (laptops, phones, tablets) connect to the internet or each other without physical cables — using radio waves instead.

Think of it this way: A wired network is like talking through tin cans connected by string. A wireless network is like talking through walkie-talkies — no string needed, but you need to be within range.

📡

Wireless Access Point

Broadcasts the Wi-Fi signal

📶

SSID

The network name you see (e.g., "BrewByte_WiFi")

🔐

Security Key

The password to join the network

2 IEEE 802.11 Wireless Standards

The IEEE 802.11 is a family of standards that define how Wi-Fi works. Think of them as "versions" of Wi-Fi — each newer version is faster and better.

☕ Back to our café: Choosing a Wi-Fi standard is like choosing a highway. 802.11b is a two-lane road. 802.11ac is a six-lane expressway. More lanes = more speed and capacity.

Standard Also Called Frequency Max Speed Year
802.11b Wi-Fi 1 2.4 GHz 11 Mbps 1999
802.11a Wi-Fi 2 5 GHz 54 Mbps 1999
802.11g Wi-Fi 3 2.4 GHz 54 Mbps 2003
802.11n Wi-Fi 4 2.4 / 5 GHz 600 Mbps 2009
802.11ac Wi-Fi 5 5 GHz 6.9 Gbps 2013
802.11ax Wi-Fi 6 2.4 / 5 / 6 GHz 9.6 Gbps 2020

📻 2.4 GHz Band

  • ✅ Longer range (goes through walls better)
  • ✅ Better for large areas
  • ❌ Slower speeds
  • ❌ More interference (microwaves, Bluetooth, neighbors)

☕ Good for reaching the café's outdoor patio

⚡ 5 GHz Band

  • ✅ Faster speeds
  • ✅ Less interference
  • ❌ Shorter range
  • ❌ Doesn't go through walls as well

☕ Perfect for streaming inside the café

3 Wireless Security Protocols

Without security, anyone nearby can snoop on your network. It's like having a conversation in a crowded café — anyone can listen unless you whisper in code. 🤫

🚫

WEP (Wired Equivalent Privacy)

Old & broken. Can be cracked in minutes. Never use this.

⚠️

WPA (Wi-Fi Protected Access)

Better than WEP but has known vulnerabilities. Avoid if possible.

✅

WPA2 (Wi-Fi Protected Access 2)

Industry standard. Uses AES encryption. This is what we'll configure in Packet Tracer.

🛡️

WPA3 (Wi-Fi Protected Access 3)

Latest & most secure. Not yet widely supported in Packet Tracer.

4 Key Terms to Remember

SSID

Service Set Identifier — the name of your Wi-Fi network

AP (Access Point)

Device that creates a wireless network for others to join

DHCP

Automatically assigns IP addresses to devices that connect

Channel

Specific frequency "lane" your router uses (1, 6, 11 are best for 2.4 GHz)

WPA2-PSK

Pre-Shared Key mode — everyone uses the same password (home/café use)

Authentication

The process of verifying a device is allowed to join the network

Guided Lab: Setting Up Wi-Fi for Brew & Byte Café

Follow these steps in Cisco Packet Tracer to build a working wireless network. We'll set up a wireless router, configure its SSID and security, and connect a laptop wirelessly.

Network Topology You'll Build

1

Open Packet Tracer & Add Devices

  1. 1. Open Cisco Packet Tracer and create a new blank project
  2. 2. From the bottom panel, click Network Devices → Wireless Devices
  3. 3. Drag a WRT300N (Wireless Router) to the workspace
  4. 4. From End Devices, drag a Laptop and a Tablet (or second Laptop)
💡 Tip: The WRT300N is a home/small-office wireless router — perfect for our café scenario!
2

Configure the Wireless Router

  1. 1. Click on the Wireless Router (WRT300N) to open its config
  2. 2. Go to the GUI tab (this simulates the router's web interface)
  3. 3. Under Setup → Basic Setup:
    • • Leave Internet Connection Type as Automatic Configuration - DHCP
    • • Router IP: 192.168.0.1 (default)
    • • DHCP Server: Enabled
    • • Start IP: 192.168.0.100
    • • Maximum Users: 50
  4. 4. Click Save Settings
3

Set the SSID (Network Name)

  1. 1. In the router GUI, go to Wireless → Basic Wireless Settings
  2. 2. Change the Network Name (SSID) from "Default" to:
BrewByte_WiFi
  1. 3. Set the Channel to 6 - 2.437 GHz
  2. 4. Click Save Settings
💡 Why Channel 6? Channels 1, 6, and 11 don't overlap with each other in 2.4 GHz. Channel 6 is a safe middle choice.
4

Configure Wireless Security (WPA2)

  1. 1. Go to Wireless → Wireless Security
  2. 2. Set Security Mode to: WPA2 Personal
  3. 3. Set Encryption to: AES
  4. 4. Set the Passphrase to:
CafeWiFi2024
  1. 5. Click Save Settings
🔐 Important: WPA2-Personal (PSK) means everyone shares the same password. For a small café, this is appropriate. Enterprises use WPA2-Enterprise with individual logins.
5

Prepare the Laptop for Wireless

  1. 1. Click on the Laptop → go to the Physical tab
  2. 2. Power off the laptop (click the power button)
  3. 3. Remove the Ethernet module (drag it out from the side panel)
  4. 4. Drag the WPC300N wireless module into the empty slot
  5. 5. Power on the laptop
💡 Why swap modules? By default, Packet Tracer laptops have an Ethernet (wired) module. We need to replace it with a wireless card (WPC300N) to connect via Wi-Fi.
6

Connect the Laptop to Wi-Fi

  1. 1. On the Laptop, go to the Desktop tab
  2. 2. Click PC Wireless
  3. 3. Go to the Connect tab → click Refresh
  4. 4. You should see BrewByte_WiFi in the list
  5. 5. Select it and click Connect
  6. 6. When prompted, enter the password: CafeWiFi2024
  7. 7. Click Connect
🟢 Success! You should see a green dot or "Connected" status. The laptop now has Wi-Fi!
7

Verify the Connection

  1. 1. On the Laptop, go to Desktop → Command Prompt
  2. 2. Type: ipconfig
  3. 3. Verify you see an IP address like 192.168.0.100 (assigned by DHCP)
  4. 4. Type: ping 192.168.0.1
  5. 5. You should receive replies — this means you can reach the router!
C:\> ping 192.168.0.1
Reply from 192.168.0.1: bytes=32 time<1ms TTL=64
Reply from 192.168.0.1: bytes=32 time<1ms TTL=64
Reply from 192.168.0.1: bytes=32 time<1ms TTL=64
Ping statistics: Sent = 4, Received = 4, Lost = 0 ✅
8

Repeat for the Tablet/Second Device

  1. 1. Repeat steps 5-7 for the Tablet (or second laptop)
  2. 2. After connecting both, ping between the two devices to confirm they're on the same network
  3. 3. From Laptop: ping 192.168.0.101 (the Tablet's IP)
